# 🚀 LeetCode GitHub Pusher

A Chrome extension (Manifest V3) that automatically syncs accepted LeetCode solutions directly into your GitHub repository with clean problem folders, metadata, and an auto-updated index README.

---

## 🌟 Features

- **Automated Pushes**: Detects accepted submissions on LeetCode and allows one-click pushing directly from the LeetCode page.
- **Structured Directory**: Creates dedicated `LC-<number>` folders containing:
  - `problem.md` (Problem description, tags, difficulty, runtime, memory, submission metadata).
  - Solution file (`solution.java`, `solution.py`, `solution.cpp`, etc.).
- **Automatic Index Maintenance**: Dynamically updates the target GitHub repository's main `README.md` with a sorted index of all solved problems.
- **Single Credentials Setup**: Configure your credentials once in `credentials.js` without messing with `.env` files or repeated popup entries.

## 🚀 Quick Setup & Installation

### 1. Configure Credentials
Open [`credentials.js`](credentials.js) in your code editor and enter your GitHub details:

```javascript
var CREDENTIALS = {
  githubUsername: "YOUR_GITHUB_USERNAME",
  githubRepo: "YOUR_GITHUB_REPOSITORY",
  githubBranch: "main",
  githubToken: "YOUR_GITHUB_PERSONAL_ACCESS_TOKEN"
};
```

### 2. Load Extension in Chrome
1. Open Chrome and go to `chrome://extensions/`.
2. Enable **Developer mode** using the toggle in the top-right corner.
3. Click **Load unpacked**.
4. Select the `LeetCode GitHub Pusher` directory.

### 3. Start Solving on LeetCode!
1. Go to any problem on [LeetCode](https://leetcode.com).
2. Submit your code.
3. Once **Accepted**, click **🚀 Push to GitHub** on the bottom-right action widget.
4. Your submission will automatically be pushed to your configured GitHub repository!

## 🔐 GitHub Access Token Setup

Create a **Fine-grained Personal Access Token** on GitHub:
1. Go to **GitHub** → **Settings** → **Developer Settings** → **Personal Access Tokens** → **Fine-grained tokens**.
2. Click **Generate new token**.
3. Select your target repository (e.g., `LeetCode-Solutions`).
4. Under **Repository permissions**, grant:
   - **Contents**: `Read and write`
5. Copy the generated token into [`credentials.js`](credentials.js).
